PIZZA CITY POS  -  Software by Ammar | 03214499478

START:   double-click start.bat (needs Node.js 18+ from https://nodejs.org), browser opens at http://localhost:3000
DATA:    saved in the "data" folder (created automatically). Backups go to "backups".
UPDATING an existing shop: copy server.js, index.html, start.bat, package.json and the "public" folder
         over your old ones. Do NOT replace your "data" folder - it holds all orders, menu and password.
Default admin password: adminpizzacity (always works, even if you set your own).
